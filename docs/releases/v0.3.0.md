# Syrinx v0.3.0 · 2026-09-13

此版本固化个人仓库、小节练习、演奏速度与音高分析更新。`dev` 对应标签 `v0.3.0`；网页分支 `web-deploy` 对应标签 `v0.3.0-web`。

## 演奏与回放

- 点击谱面小节选择起点；就绪和暂停时保持停止，播放中先封存当前录音，再倒数四拍继续。
- 每次跳转保留此前录音；回放可选择分段，并按对应区间对照伴奏、分析音高。
- 底部 BPM 面板提供推荐初值、数值输入、滑块和还原推荐；支持原谱初始速度的 0.5–1.5 倍，伴奏保持原调，谱内速度变化按比例保留。
- 演奏中应用速度先保留当前录音，再倒数继续；每段保存独立速度，回放时自动恢复并校正录音与伴奏的启动偏差。
- 优化快速连续操作的取消逻辑，以及手机、平板和折叠屏尺寸下的谱面与控件布局。
- 修正原生音频时间舍入导致的小节回退；录音真正开始后才亮起 REC，等待授权和失败状态有明确提示。

## 更快的音高反馈

- 音高提取移入后台 Worker，显示分析进度；切换录音段会取消旧分析，避免旧结果覆盖当前选择。
- 优化离线 YIN 的计算范围与提前结束逻辑；评分口径保持不变。
- 本机 Node 合成样本基准：60 秒提取由约 3.18 秒降至 0.35 秒。内置浏览器生产 Worker 分析另一份 60 秒合成样本约 0.52 秒；这些是可重复测试样本的测量，不代表所有录音或设备。
- [算法基准与精度检查](../../app/src/pitch/benchmark.md)。

## 个人仓库与界面

- 正式版支持本地 MusicXML/MXL 导入、电子阅谱、单钢琴声部伴奏、名称与作者编辑、封面、文件夹、收藏、分页及卡片/列表切换。
- 单长笛谱只阅谱，不生成音频。仓库突出导入、搜索和打开，低频操作收纳到菜单。
- 网页体验版同步精选/个人仓库选项卡与主要界面样式。点击个人仓库显示正式版本提示，不开放导入或本地仓库管理。

## 曲目与发布边界

- dev 精选曲库移除《鸟之诗》和《River Flows in You》，保留 Luv Letter、Flower Dance、Lumière、Alicia、Interstellar、Weight of the World 六首。
- web-deploy 保留原有四首发布清单：Luv Letter、Flower Dance、Lumière、Interstellar。
- 移除仅针对内置精选曲目；用户个人仓库中的同名文件不受影响。
- 标签固化源码。未提供 Windows、Android 或 Apple 安装包，也不把分支推送等同于云服务器部署。
