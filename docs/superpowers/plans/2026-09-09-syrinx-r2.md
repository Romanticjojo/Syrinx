# Syrinx R2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Deliver independent bar-loop recordings, weak-bar retry, and persistent local history to dev and Alibaba.

**Architecture:** Pure practice model and IndexedDB persistence support existing recording and result flows. Each loop seals independently; history reconstructs temporary URLs and guards scoring versions.

**Tech Stack:** Existing React 19, Zustand, Web Audio, TypeScript, Vitest; browser IndexedDB.

**Spec:** docs/superpowers/specs/2026-09-09-syrinx-r2-design.md

## Global Constraints

- Preserve private media, user untracked files, R1 correctness and loading behavior.
- No server recording upload, accounts, or cross-origin history sync.
- No raw playbackRate slider in R2; R3 remains separate.
- Existing Take additions optional for legacy compatibility; all new R2 records fully versioned.
- Commit only owned paths; no pushing or deploying by implementation workers.

### Task 1: Practice model and persistent history

**Files:** create app/src/practice/model.ts, history.ts, corresponding tests; extend app/src/types.ts only if shared fields needed.

**Interfaces:**
- `PracticeRange { startMeasure: number; endMeasure: number; startSec: number; stopSec: number }`; measure labels are playback ordinals 1..N to avoid repeated printed numbers.
- `PracticeConfig { songId: string; range: PracticeRange; rounds: number }`.
- `PracticeMetadata { songVersion: string; scoringVersion: string; range: PracticeRange | null; groupId: string; round: number; rounds: number }`; Take optional `practice?: PracticeMetadata`, `audioBlob?: Blob` for current in-memory result.
- `practiceMeasures(timeline: Timeline): PracticeRange[]`; one interval per played bar.
- `practiceRange(timeline: Timeline, startMeasure: number, endMeasure: number): PracticeRange | null`; reject invalid/noncontiguous/out-of-bound integers.
- `songVersion(xml: string, timeline: Timeline): string`; stable version from actual content.
- `SCORING_VERSION` fixed R2 literal `pitch-v2-captured-notes`.
- `weakMeasures(result: ScoreResult, timeline: Timeline): Array<{range:PracticeRange; missed:number; total:number; avgAbsCents:number}>`; worst up to 3 bars by missed ratio then cents, no fabricated measured precision on all-miss bars.
- `StoredPractice = Omit<Take,'audioUrl'|'audioBlob'> & { schemaVersion: 1; audioBlob: Blob; practice: PracticeMetadata }`.
- `savePractice(take: Take, blob: Blob): Promise<void>`; requires complete metadata, upsert by sessionId.
- `listPractices(): Promise<StoredPractice[]>` newest first; `getPractice(id:string): Promise<StoredPractice|undefined>`; `deletePractice(id:string):Promise<void>`; `clearPractices():Promise<void>`.
- `updatePracticeAnalysis(id:string,pitchTrack:PitchPoint[],stats:TuneStats):Promise<void>` updates existing only, never resurrects deleted entry.
- `comparisonReason(a:StoredPractice,b:StoredPractice):string|null`; null only fully compatible including actual capture bounds.

- [ ] Write meaningful failing tests first: timeline with duplicate printed bar numbers produces 3 independent playback intervals, invalid bounds return null; XML or anchor timing change changes version. `expect(practiceRange(tl,2,2)).toMatchObject({startSec:2,stopSec:4})`.
- [ ] Run targeted Vitest and record RED evidence.
- [ ] Implement pure functions and transactional IndexedDB repository; validate required fields before save. A transaction that aborts after request success must reject.
- [ ] Tests exercise CRUD with real IndexedDB-compatible test implementation if available; otherwise use narrow event-driven adapter tests AND require real browser persistence acceptance later. Do not add production dependencies just for tests. Test Blob survives roundtrip, ObjectURL absent, quota rejection, update-after-delete no recreation, compatibility errors.
- [ ] Run targeted tests/build type check as applicable; report evidence and exported interfaces; commit owned files.
