## 用户体验

- 现有首页的精选媒体、轮播和卡片保留；曲库区增加精选乐谱、个人仓库选项卡。
- 正式版仓库包括空态、导入、搜索、最近打开、收藏、全部乐谱、标题/作者/标签编辑、删除确认、备份导出与恢复。
- MusicXML / XML / MXL 导入先检查文件及声部，再由用户确认主旋律、钢琴声部和伴奏模式。重复内容不覆盖已有编辑。
- 乐谱详情显示原谱、主旋律、钢琴谱（存在时），可缩放；开始演奏复用现有演奏、录音、回放流程。
- 风格绑定 app/src/index.css 和 docs/设计/style-tokens.md：夜航晨光、衬线曲名、青色点缀、细线及深浅主题。Netflix 参考体现在横向最近访问、内容卡片、详情入口；不改变品牌色。
- 所有弹层有标题、关闭、Escape、焦点约束及焦点归还；触屏目标至少 44px，窄屏无横向溢出。

## 本地模型与可靠性

- PersonalScore 原始 XML、元数据、设置、时间戳和内容 SHA256 保存在 IndexedDB；不存临时 Object URL，不发网络请求，不需要账号。
- 原文件永不被编配或排版覆盖。备份 JSON 有 schema version、完整记录验证、大小上限和事务性合并恢复；不会清空现有仓库。
- IDB 的所有写入以事务 complete 为成功，失败返回可理解错误。搜索匹配标题、作者、标签。重复导入通过 fingerprint 去重。
- 上层依赖仓库接口，后续原生文件系统/数据库可以替换底层。当前正式功能预览尚不是原生持久化保证，需提供备份。

## 解析与伴奏

- 多 part、voice、staff 音符按四分音符坐标解析，共享 tempo map；backup/forward、chord、rest、tie、tuplet、弱起、常见反复及时值变化有手算测试。
- 支持 score-partwise；遇 score-timewise 或复杂导航等未覆盖语义时明确说明，禁止静默错误播放。允许纯阅谱模式保留内容。
- 原谱伴奏模式播放用户所选钢琴声部。纯旋律模式优先读取 harmony，否则用调性与重拍音推断三和弦；支持 block/arpeggio/waltz 三种基础伴奏型，可覆盖调性。默认不将主旋律混入伴奏。
- 纯阅谱模式不生成伴奏；演奏时使用与谱长一致的静音缓冲维持既有主时钟。
- 钢琴为离线合成音色，明确标注。目标是基础练习伴奏，不承诺还原人工编配或真实钢琴录音。
- 渲染 XML、旋律评分和钢琴声部使用一致的展开播放顺序；原始阅谱使用未展开 XML。
- 文件、解压总量、音符数及曲长设上限。生成可取消，长处理分批让出线程。只缓存当前曲目的伴奏，设置变化使缓存失效。
