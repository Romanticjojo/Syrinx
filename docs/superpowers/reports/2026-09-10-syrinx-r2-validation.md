# Syrinx R2 实施与验收

验收日期：2026-09-10（香港时间）。R2 已合入本地 dev 与 web-deploy，并更新阿里云。

## 交付范围

- 选择实际播放顺序的小节区间，1–5 轮练习，每轮独立录音与保存。
- 当前浏览器 IndexedDB 保存录音、曲谱与评分版本、轮次、范围和分析；刷新后可打开、下载、删除。
- 薄弱小节三轮重练；仅比较曲谱、评分、范围和实际完整音符集合兼容的记录。
- 麦克风等待、不可用和关闭录音状态持续可见；REC 只表示实际开始采集。
- 手机首页保留练习记录入口。

## 验证证据

dev 与四曲 web-deploy 各 42 个文件 / 383 项测试通过，两者生产构建通过。独立任务审查和最终复核通过。集成并行测试曾暴露固定 180ms 等待的不稳定断言，已改为等待实际分析保存调用完成；后续两套全量验证通过。小屏修复只改 CSS，以真实浏览器验证，无新增镜像样式单测。

开发版按六曲配置验证；部署版按四曲和 m4a 配置验证。在 dev 分支强行套四曲环境时，原有 syncList 测试的六曲断言失败；实际 web-deploy 保留其四曲断言并通过，未改断言掩盖分支差异。

浏览器实际操作：

- 隔离网址 127.0.0.1:5175 的明确标注合成音验收页，使用 440Hz 输入送入真实 recorder、AudioWorklet、WAV、分析及 IndexedDB。两次跑完三轮，各出现三个独立记录。
- 完整刷新后记录保留；打开上一轮重新分析，再打开后一轮显示兼容成绩差值。刷新后的对照播放实际启动。
- 下载文件经媒体检查为 32kHz、单声道、16 位 PCM WAV，2.832 秒、181292 字节。
- 薄弱小节入口正确返回第 1–1 小节、三轮练习；Esc 可退出准备页。删除取消保留记录，确认删除只去除一条；清空隔离测试记录后刷新显示空列表。
- 320px 导航按钮均在视口内、触控高度 44px；390px 分段控件和记录页无水平溢出。390px 三轮结果、768px 空记录页实际截图检查通过。临时视口覆盖已恢复。
- 正式网址 romanticjojo.com 原生录音成功保存一条第 1–3 小节、1 轮、约 8.48 秒记录，完成分析并实际启动对照回放。未将该录音上传服务器，保留在该浏览器网址的本地记录中。
- localhost 开发版刷新可见记录入口，正式版显示四首曲目及版本化新脚本；验收页和正式页未捕获运行错误。

首次本地未获得麦克风时正确进入无录音结果；修复后的持续不可用提示、迟到授权、重试及三轮偏好由回归测试覆盖。线上此次浏览器麦克风可用，不声称在线实测了拒绝权限路径。

## 范围限制

合成信号与浏览器录音证明流程可用，不代表真实长笛评分准确度、手机硬件性能或主观听感已通过评测。浏览器输出的音准数字未作为实际演奏水平结论。记录按浏览器和网址隔离，不在 localhost 与公网之间同步；录音未上传。生产构建仍有既有 OSMD/演奏包体积提示，测试仍有既有 React act 提示。

R3 保音高慢练、变速录音映射和实验性起音参考在独立分支实施，不包含在本 R2 发布中。
