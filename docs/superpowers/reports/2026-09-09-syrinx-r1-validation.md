## 性能对比

2026-09-09，相同电脑与网络路径，用 5 次独立 curl 进程下载，启用 HTTP 压缩、没有浏览器缓存。下列时间是 HTTP 下载时间，不含页面渲染或音频解码。

| 资源 | 实际传输字节 | 完整下载中位数 | 范围 |

| 旧首页主 JS | 698,695 | 3.76 秒 | 2.81–4.39 秒 |
| 新首页主 JS | 110,078 | 2.30 秒 | 2.17–2.94 秒 |
| 新首页运行时 JS | 716 | 2.00 秒 | 1.46–2.28 秒 |
| 旧路径 Flower Dance AAC | 3,241,699 | 9.04 秒 | 8.52–12.84 秒 |

新版首页两份脚本合计 110,794 字节，减少 **84.14%**。构建器显示的约 97 KB 是其 gzip 估计；阿里云实际压缩配置下是上表约 111 KB，交付结论以实际 HTTP 数据为准。

每个资源独立建立连接，表中两份新脚本的时间不能相加当作浏览器首屏时间。主 JS 首字节中位数从 2.75 秒变为 1.75 秒，包含网络/连接差异，不能把全部时间收益归因于代码拆分。伴奏复用原线上优化 AAC，没有再次压缩，冷下载并未变快；主要收益是进入预览即准备、进入演奏复用同一下载/解码结果。

逐次原始数据见同目录 `2026-09-09-syrinx-r1-http.json`。预加载去重、取消迟到下载与解码、失败重试、保留当前已解码伴奏由自动化测试验证；浏览器也检查了加载中/已准备状态与页面衔接。本轮未获得浏览器 Resource Timing 与堆内存采样，因此没有编造浏览器缓存/已解码缓存各五次耗时或内存释放曲线。
