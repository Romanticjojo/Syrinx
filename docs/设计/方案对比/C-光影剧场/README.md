# 方向 C「光影剧场」

> 发散档 · 电影化实验。打开 `preview.html` / `perform.html` 查看。

## 设计立场

把应用当"一场放映"：预览页是全屏预告片 + 片名字幕卡，演奏页是剧场舞台——上下遮幅定场、追光光锥打在谱面幕布上、小节号以"Scene 场次"呈现。

## 关键选择

- **布局**：预览页 = 全屏影像 + 居中字幕卡（kicker → 巨型衬线片名 → 分隔线署名 → 数据条 → CTA）+ 放映表式曲库（罗马数字编号）；演奏页 = 幕布卡片谱面（4px 锐角 + 两侧金色光边）+ 极简细线控制（藏进遮幅）
- **排版**：极细字距（.34em–.5em）全大写小字 与 衬线巨字（110px）对撞；斜体衬线歌词
- **配色**：纯黑 `#050507` + 单色暖金 `#e8c07a`，一色到底
- **动效**：放映机光束 16s 缓慢摆动、浮尘颗粒、扫描线颗粒噪点、追光呼吸；一切缓慢克制
- **沉浸感策略**：遮幅 + 噪点 + 光束三重"影院信号"，仪式感最强

## 权衡

- 强在：记忆点与仪式感最强，最贴 Lumière"夜与光"叙事（Expedition 33 美术向）；"Scene"概念让长曲子有章节感
- 弱在：上下遮幅吃掉约 13% 垂直空间，谱面可用高度最少；极端排版信息效率最低（找一首曲子的元数据要扫读）；"剧场"概念对日常练琴是持续成本——新奇感会衰减，可用性损失是永久的

## 适用于

概念展示、首发宣传页，或每曲独立"特别放映"入口；作为日常练琴主界面风险高。
