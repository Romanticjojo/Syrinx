# 方向 A「夜航晨光」

> 保守档 · v1/v2 初稿的精修定深版。打开 `preview.html` / `perform.html` 查看。

## 设计立场

编辑感 Netflix hero：预览页像一篇图文并茂的乐曲推荐，演奏页是"舞台上的玻璃谱面板"——信息完整、层次清晰、风险最低。

## 关键选择

- **布局**：预览页 = 左信息右光景 hero + 下方卡片行；演奏页 = 居中玻璃谱面面板（近黑 87% + blur(14px)）+ 底部控制条
- **排版**：衬线大标题（Georgia/思源宋体）承担情绪，无衬线 UI 字承担功能；字阶落差大（72px → 12px）
- **配色**：暗底 `#0b0b0f` + 暖金 `#d9a441`（强调/光标）+ 晨光青 `#5fb8a8`（数据/次强调），双色克制使用
- **动效**：hero 渐变 22s 缓慢漂移、光尘微粒上升、倒数脉冲、控件 3.2s 自动隐藏；`prefers-reduced-motion` 全尊重
- **沉浸感策略**：预览页"热闹"（动画+光效），演奏页"冷静"（面板把背景隔开，只留金线导光）

## 权衡

- 强在：谱面可读性最稳（面板硬隔离）；信息传达效率最高；实现风险最低
- 弱在：玻璃面板削弱沉浸感（谱子像"浮在窗后"）；视觉记忆点一般；每曲换主题的氛围延展性弱（全局一套金青色）

## 适用于

重视信息效率与稳妥可读的练琴工具定位。
