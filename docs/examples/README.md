# 原创示例乐谱 · Original example scores

这两份短练习为 Syrinx 文档与功能演示原创，随项目按 [Apache License 2.0](../../LICENSE) 提供。截图中的曲名、标签和文件夹是演示用的本地编辑信息。

These short studies were written for Syrinx documentation and demonstrations and are provided under the project's [Apache License 2.0](../../LICENSE). Titles, tags and folders shown in screenshots are local demonstration metadata.

| 文件 / File | 声部 / Parts | 用途 / Purpose |
|---|---|---|
| [morning-light.musicxml](morning-light.musicxml) | 长笛 + 一个双谱表钢琴声部 / Flute + one two-staff piano part | 阅谱、原谱钢琴伴奏、BPM 与分段录音 / Reading, original piano accompaniment, tempo and recording segments |
| [breath-study.musicxml](breath-study.musicxml) | 单长笛 / Solo flute | 仅阅谱，不生成音频 / Reading only, without audio generation |

在 `dev` 分支的 `app` 目录执行 `npm run dev`，打开「个人仓库 → 导入乐谱」，选择任一文件。Morning Light 可选择「钢琴伴奏」；Breath Study 自动使用「仅阅谱」。网页体验模式只显示个人仓库的正式版本提示。

Run `npm run dev` from `app` on the `dev` branch. Open “个人仓库” (Personal library), choose “导入乐谱” (Import score), and select either file. Morning Light supports “钢琴伴奏” (Piano accompaniment); Breath Study uses “仅阅谱” (Read only). Web demo mode shows a full-version notice for the personal library.
