# 长笛演奏辅助应用 · 需求文档

> 项目代号：暂定 **FluteFlow**（后续可改）。阶段一产出，作为后续 UI 初稿与 MVP 开发的唯一需求基准。
> 参考材料：《调研分析-可复用项目.md》（63 条项目来源）。

## 1. 一句话定位

一款"Netflix 式"的长笛演奏辅助 Web 应用：像刷剧一样挑选曲目，进入后跟着曲谱节拍演奏，动态背景与伴奏营造沉浸感，录下自己的演奏回放分享。

## 2. 目标用户与场景

- 长笛学习者与业余爱好者（有基本读谱能力）
- 单人练习场景：家中、琴房，手机或电脑浏览器
- 核心体验诉求：**沉浸、专注、不被 UI 干扰**（UI 是舞台，不是主角）

## 3. 技术形态建议：Web（SPA/PWA）

| 方案 | 结论 |
|---|---|
| **Web 网页（推荐）** | 调研到的核心库（OSMD/VexFlow/alphaTab/abcjs、Web Audio、three.js）全部是浏览器端方案；开发迭代快；PWA 可"添加到主屏幕"接近原生体验 |
| 桌面/移动原生 App | 仅当后期需要极低延迟音频、后台播放时再考虑（可复用 Web 技术栈：Tauri / Capacitor 壳） |

浏览器端限制需要正视（详见《技术选型.md》）：
- 蓝牙耳机有 100–300ms 音频延迟，练琴建议提示用户用扬声器或有线耳机
- 麦克风音高检测受环境噪音影响，MVP 以"节拍跟随"为主、听音检测为 P2
- iOS Safari 对 Web Audio/录音有一些限制，移动端以 Android Chrome + 桌面为主战场

## 4. 用户流程（北极星路径）

```
首页（Netflix 式曲库墙）
  → 点击曲目卡片 → 「预览页」（自动播放片段动画 + 伴奏音频，Netflix 预告片体验）
  → 点击「开始演奏」→ 演奏界面（曲谱跟随 + 节拍提示 + 伴奏 + 动态背景）
  → 演奏结束 → 录音回放页（试听 / 重新演奏 / 保存）
```

### 4.1 入场：长笛结构蓝图拼装动画

- 演奏开始前播放一段"长笛结构拼装"动画（各部件按顺序组装成完整长笛），作为品牌化入场仪式
- 动画/3D 模型素材由**用户外部生成**（Blender/Three.js 导出 glTF 或 AE 导出视频），本应用只负责播放与编排
- 形式待定：视频（mp4/webm，简单可靠）或 glTF 实时渲染（可交互，成本高）——建议 MVP 用视频，后期升级
- 用户可勾选"下次跳过"

### 4.2 Netflix 式预览页

- 参考交互：Netflix 桌面端详情页——鼠标悬停卡片即开始静音预览，进入详情页自动播放预告片
- 预览内容 = 该曲目的"部分动画 + 伴奏音频"片段（素材用户外部生成，每曲一份 preview.mp4 或 图片+音频）
- 页面元素：大标题、作曲者、难度、时长、曲目简介、「▶ 开始演奏」「＋加入收藏」
- 悬停卡片：卡片放大 + 播放静音预览片段（P1）

## 5. 功能清单与优先级

### P0 — MVP 必须（演奏核心闭环）

| # | 功能 | 说明 |
|---|---|---|
| P0-1 | 曲库首页 | Netflix 式横向卡片墙：封面 + 标题 + 难度；桌面横向滚动行、移动端纵向流 |
| P0-2 | 曲目预览页 | 自动播放片段动画 + 伴奏音频；「开始演奏」入口（见 4.2） |
| P0-3 | 曲谱渲染 | 浏览器渲染 MusicXML 曲谱（引擎选型见《技术选型.md》）；支持缩放 |
| P0-4 | 曲谱跟随（节拍驱动） | 按曲谱节拍时间轴高亮当前小节/音符，光标自动推进；**由伴奏音频时钟驱动**，保证谱、音、光标三者同步 |
| P0-5 | 自动翻页/滚动 | 光标推进时自动滚动视口（OSMD 内置 followCursor 或自行平滑滚动） |
| P0-6 | 背景伴奏播放 | Web Audio 播放每曲伴奏（音频文件用户外部准备），与曲谱时间轴对齐 |
| P0-7 | 动态背景（每曲） | 每首曲目配一个动态背景，贴合乐曲风格；谱面区域保证对比度、谱子可读优先；素材/着色器用户外部生成，播放器只做叠加与透明度控制 |
| P0-8 | 录音与回放 | MediaRecorder 录制用户演奏（麦克风），演奏结束即时回放 |
| P0-9 | 长笛拼装入场动画 | 播放外部生成的拼装动画视频（见 4.1），可跳过 |
| P0-10 | 沉浸式演奏界面 | 全屏、深色、控件自动隐藏；简洁大气（参考 Netflix/Spotify 的暗色控制层） |

### P1 — 体验增强（MVP 后第一批）

| # | 功能 | 说明 |
|---|---|---|
| P1-1 | 节拍器 + 倒数入场 | 演奏前 4 拍倒数；节拍可视化（脉冲/光带） |
| P1-2 | 速度调节 | 伴奏与时间轴整体变速（0.5x–1.2x），变速不变调 |
| P1-3 | 曲谱难度标注 | 每曲难度等级（入门/进阶/演奏级）显示在卡片与预览页 |
| P1-4 | 收藏/历史 | 收藏曲目；记录最近演奏 |
| P1-5 | 悬停静音预览 | 首页卡片 hover 即播放预览片段（完整 Netflix 交互） |
| P1-6 | 录音管理 | 录音列表、命名、下载（webm/mp3） |
| P1-7 | 移动端适配 | 响应式布局，平板/手机可演奏 |

### P2 — 智能化（远期）

| # | 功能 | 说明 |
|---|---|---|
| P2-1 | 麦克风音高检测 | 实时检测演奏音高（CREPE/tfjs 或 MPM/WASM），曲谱上标注演奏准确性 |
| P2-2 | 跟随演奏推进（听音驱动） | 以用户实际演奏（而非固定节拍）驱动光标推进 —— Tonara/Yousician 模式 |
| P2-3 | 评分与反馈 | 音准/节奏准确度评分、错音高亮 |
| P2-4 | 游戏化 | 连击、星级、进度激励（参考 Sky/节奏游戏） |
| P2-5 | 动态背景生成器 | 应用内按曲目风格一键生成 audio-reactive 背景（降低外部素材依赖） |

### 暂不做（明确排除）

- 账号系统/云同步/多端登录（本地 localStorage 即可）
- 曲谱编辑器
- 社交/分享平台（录音仅本地）
- 五线谱以外的谱式（简谱等，如 alphaTab 支持可作为免费彩蛋）

## 6. 关键体验原则

1. **谱子永远可读**：动态背景再华丽，也要通过遮罩/暗化/模糊保证谱面对比度；对比度是硬约束，背景华丽度可降级
2. **同步是生命线**：曲谱光标、伴奏、节拍提示必须同源驱动（音频时钟），误差感知阈值 < 50ms
3. **两极界面**：首页/预览页可以热闹（Netflix），演奏页必须冷静（只有谱子和必要的控制）
4. **素材与引擎分离**：动画、伴奏、背景均为每曲配置的外部素材（manifest 描述），应用是"播放器+同步引擎"，不做内容生产

## 7. 内容组织：曲目包（Song Pack）格式约定

每首曲目一个目录（或 manifest JSON），后续任务按此对接：

```
songs/lumiere/
├── manifest.json      # 元数据：标题、作曲者、难度、时长、风格标签、素材文件索引
├── score.musicxml     # 曲谱（必选）
├── accompaniment.mp3  # 伴奏音频（必选）
├── preview.mp4        # 预览页片段动画（可选，缺省用封面图+伴奏）
├── intro.mp4          # 入场拼装动画（可选，全局默认一份亦可）
└── background/        # 动态背景素材（视频 mp4/webm 或 shader 配置，可选）
```

首发示例曲：**Nocturne pour Lumière**（Clair Obscur: Expedition 33，Lorien Testard）——需用户自行准备 MusicXML 曲谱与伴奏音频（版权原因应用不分发）。

## 8. 里程碑建议

| 里程碑 | 内容 | 对应优先级 |
|---|---|---|
| M1 预览+渲染 | 曲库首页、预览页（静态素材）、曲谱渲染 | P0-1/2/3 |
| M2 同步演奏 | 伴奏+光标跟随+自动滚动+动态背景叠加 | P0-4/5/6/7/10 |
| M3 录音闭环 | 录音回放、入场动画、沉浸控件 | P0-8/9 |
| M4 体验增强 | 节拍器、变速、收藏、悬停预览、移动端 | P1 |
| M5 听音智能 | 音高检测、跟随推进、评分 | P2 |
