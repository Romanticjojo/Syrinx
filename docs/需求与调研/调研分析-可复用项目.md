## 初步结论（供规划参考）

- 曲谱渲染/跟随：OpenSheetMusicDisplay、VexFlow、alphaTab、abcjs（带播放高亮）为浏览器端主力方案

- 演奏跟练参考：Tonara（听音跟随）、Yousician/tonestro（音高检测练习）、Sky: Children of the Light（音乐游戏化）

- 音高检测：CREPE（tensorflow.js/WASM 实时）

- 录音回放：Web Audio API + MediaRecorder

- 动态背景：three.js audio-reactive shaders（音频响应着色器）

- 节奏游戏框架参考：osu / StepMania / Etterna（可不复用代码，仅借鉴交互）

- 示例曲：Clair Obscur: Expedition 33 - Nocturne pour Lumière（fandom 词条可查）
